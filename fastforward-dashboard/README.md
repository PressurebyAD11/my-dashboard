# fastforward-dashboard

Project scaffold for the FastForward dashboard application.

## Local login (development)

Use these default credentials for local testing:

- Username: `ops.manager`
- Password: `fastforward2026`

After login, the client stores a session token and routes to the dashboard automatically.

You can override the defaults with environment variables before starting the server:

- `DASHBOARD_USER`
- `DASHBOARD_PASS`
